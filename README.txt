LOVE MAY ♡ — เว็บไซต์ความทรงจำ

วิธีดูเว็บ:
1. แตกไฟล์ love-may-website.zip
2. เปิด index.html ในเบราว์เซอร์เพื่อดูตัวอย่าง
3. หากต้องการเผยแพร่สาธารณะ ให้อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง GitHub Pages, Netlify หรือบริการโฮสต์เว็บแบบ static

ไฟล์รูปและเพลงอยู่ใน assets/ อย่าย้าย index.html ออกจากโฟลเดอร์หลัก
หมายเหตุ: iPhone/Safari อาจไม่อนุญาตให้เล่นเพลงอัตโนมัติก่อนผู้ใช้แตะปุ่มเล่น
